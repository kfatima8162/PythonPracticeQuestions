## 📌 About This Repository

This repository is a living record of my Python programming journey. Every day, I solve approximately **20 Python questions** sourced from [W3Resource](https://www.w3resource.com/python-exercises/) — one of the most comprehensive platforms for Python practice problems. Each session is saved as a standalone Jupyter Notebook, making it easy to track progress, revisit solutions, and share knowledge with the community.

## 🚀 How to Run

Follow these steps to clone the repository and explore the notebooks locally:

**1. Clone the repository**

```bash
git clone https://github.com/kfatima8162/PythonPracticeQuestions.git
```

**2. Navigate into the project directory**

```bash
cd PythonPracticeQuestions
```

**3. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**Or launch JupyterLab**

```bash
jupyter lab
```

**Or open in VS Code**

```bash
code .
```

> Then open any `.ipynb` file using the Jupyter extension in VS Code.
